# User Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A top-right Menu with theme, text size and admin sign-in / Data fixes / Migration status / Sign out.

**Architecture:** A `UserMenu` component replaces `ThemeToggle` in `Header`. Text size is a stored
preference applied as an `html.text-large` class (same pattern as the theme). The footer link and
`RequireAdmin`'s email/Sign out bar are removed; the menu carries them.

**Tech Stack:** React 19 + TS + Tailwind, react-router, vitest (node, no DOM testing library).

**Spec:** `docs/superpowers/specs/2026-11-16-user-menu-design.md`

## Global Constraints

- Theme storage key stays `picaloco-theme`; text size key is `picaloco-text-size`, values `normal` | `large`.
- Large = root font size × 1.125 on every page, including on top of `html.scale-text`.
- Menu items: Theme (System / Light / Dark / Bespoke), Text size (Normal / Large), then
  signed out: "Sign in (admin)" → `/admin/fixes`; admin: email, "Data fixes" → `/admin/fixes`,
  "Migration status" → `/admin`, "Sign out"; signed in but not admin: email, "Sign out".
- Touch targets `min-h-11`; button has `aria-expanded`/`aria-haspopup="menu"`; Escape and click-outside close.
- localStorage reads/writes wrapped in try/catch (existing `useTheme` pattern).

## Review Focus

- Keyboard on a review page: with focus on the Menu button or inside the open menu, Enter/arrows/S/X/N
  must not reach the review page's window `keydown` handler (no accidental Save & next). Pin: the menu
  root's `onKeyDown` calls `e.stopPropagation()`; verify in the browser (Task 2 Step 4).
- Navigating via a menu link closes the menu.
- Sign out from the menu while on `/admin/fixes/...` returns to the sign-in form (RequireAdmin reacts to the auth change).
- localStorage unavailable: menu still works, text size falls back to normal.
- Review page at 1920×970 with Normal text still has no page scroll after the RequireAdmin bar is removed.
